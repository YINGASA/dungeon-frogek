# 第一关美术风格基线

本文档定义《灵墟地牢》第一关的美术方向、尺寸建议和可读性规则。V1.5.1 只确立风格基线，不接入新的角色或武器 sprite sheet，不改变当前游戏画面和玩法。

## 项目美术定位

《灵墟地牢》第一关采用俯视角地牢表现：

- 俯视角 / top-down dungeon。
- 暗色地牢底色，强调地下遗迹的压迫感。
- 青绿色源晶科技感，作为第一关最强识别点。
- 轻微像素风或低分辨率清晰风格，优先保证战斗中可读。
- 重点突出角色、怪物、门、弹道、危险区域、奖励物和可交互物。
- 不追求复杂写实建模，不做过度精细的光影堆叠。
- 第一目标是统一风格、清晰可读、战斗反馈明确。

地图可以有氛围，但不能喧宾夺主。玩家必须在移动、攻击、冲刺、护盾、受击和选择路线时快速读懂屏幕。

## 推荐像素尺寸

| 资源类型 | 推荐尺寸 | 说明 |
| --- | --- | --- |
| 地图 tile | 32x32 | 当前更推荐，兼顾细节和可读性 |
| 备选地图 tile | 16x16 | 更省资源，但细节少，容易显得拥挤 |
| 玩家角色基础帧 | 32x32 或 48x48 | 32x32 更干净，48x48 可容纳更多动作细节 |
| 小怪 | 32x32 | 保持和玩家接近的屏幕识别尺度 |
| 精英怪 | 32x32 或 48x48 | 可用更大轮廓或特效表达强化 |
| Boss | 64x64 或更大 | 需要明显压迫感和技能预警空间 |
| 武器攻击特效 | 48x48 / 64x64 / 96x96 | 根据短剑、重刃、长枪、双匕差异决定 |
| UI 图标 | 32x32 | 保持清晰、统一、易缩放 |

16x16 资源更轻量，适合装饰、碎片和低密度小图标，但角色和战斗对象会损失动作细节。32x32 更适合当前项目：读取成本低，地图 tile 能承载裂纹、晶体、墙面边缘和污染纹理。

角色攻击动画不宜做得过大。动画画面如果远大于实际判定，会造成“看起来打中了但没有命中”的错觉；如果视觉范围小于判定，会造成“隔空命中”的错觉。武器动画只做表现，必须跟随现有判定，而不是驱动伤害、击退或冷却。

## 第一关视觉关键词

灵墟地牢的视觉关键词：

- 源晶
- 污染
- 封尘石墙
- 青绿色光效
- 裂隙
- 符文
- 地下遗迹
- 腐化晶体
- 破损祭坛
- 封尘宝库
- 暗色地面
- 高亮交互物

这些关键词应优先体现在第一关地图 tileset、房间装饰、宝库、商人、事件物体、Boss 领域和危险提示上。

## 色彩建议

基础色建议：

- 深蓝黑：地牢暗部、背景深层、屏幕边缘压暗。
- 暗灰石砖：墙体、地面、台座和遗迹结构。
- 冷青色源晶：源晶、门、传送门、可交互能量。
- 紫色污染：腐化地面、毒雾、异常状态和危险区域辅助色。
- 金色奖励 / 宝箱：奖励、金币、宝库和高价值交互物。
- 红色危险提示：Boss 技能、电报圈、受伤警示。
- 白色 / 黄色伤害数字：普通伤害和高亮伤害反馈。

可读性要求：

- 玩家和敌人必须从地图背景中明显分离。
- 弹道、危险提示和 Boss 技能范围必须比地面装饰更清晰。
- 宝箱、商人、事件物体、门和传送门需要高亮边缘或稳定光源。
- 地图纹理不要太花，避免裂纹、晶体和污染纹理遮住战斗信息。
- 同屏多个特效时，优先保证玩家位置、敌人轮廓、伤害数字和危险区可见。

## 房间风格基线

出生房：

- 安全、干净，源晶微光更柔和。
- 操作提示区域保持清晰。
- 不使用强危险色。

普通战斗房：

- 普通污染地面。
- 少量裂纹和源晶碎片。
- 装饰密度低，给战斗移动留出视觉空间。

高级战斗房：

- 更强污染和地面裂隙。
- 危险感更高，但不要遮挡弹道。
- 可增加符文残片或腐化晶体。

精英战斗房：

- 精英符文和压迫感更强。
- 敌人强化需要有视觉提示。
- 地面可以更暗，但交互门和奖励必须醒目。

封尘宝库：

- 宝箱台座、封尘石台、金色或青绿色资源光效。
- 奖励物和宝箱必须是第一视觉层级。

事件房：

- 随机遭遇氛围。
- 未来可扩展陷阱、祭坛、毒雾、武器架等主题物。
- 事件物体必须和普通装饰区分开。

封尘商人：

- 商人台、交易光源、金币和源晶道具陈列。
- 交互范围提示要比背景装饰更明确。

Boss 房：

- 更大空间压迫感。
- Boss 领域边界清晰。
- 技能范围提示比地面装饰和特效更优先。
