# relic_hunter

Future sprite sheets for the default hero, including:

- `relic_hunter_idle.png`
- `relic_hunter_walk.png`
- `relic_hunter_hurt.png`
- `relic_hunter_death.png`
- Future weapon-specific attack sheets if they are kept with the hero

Recommended frame size: 32x32 or 48x48.

Formal resources should keep consistent facing, origin, silhouette scale, and frame count rules across idle, walk, hurt, death, and attack-related animations. Animation must not change movement speed, collision size, attack hitboxes, damage, knockback, or J/K/L timing.
