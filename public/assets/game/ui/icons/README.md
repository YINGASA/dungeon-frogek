# icons

Future UI icons for first-floor resources, status, shop items, and relic categories.

Recommended icon size: 32x32.

Icons should keep a consistent outline, contrast, and color language. Gold-related icons should read as rewards or currency, cyan-green icons as source-crystal or interaction energy, purple icons as corruption/status, and red icons as danger or damage. UI icons should remain clear at small size and should not require new runtime dependencies.
