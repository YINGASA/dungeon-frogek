# rune_archer

Future rune archer sheets. Use names such as `rune_archer_idle.png`, `rune_archer_move.png`, `rune_archer_attack.png`, `rune_archer_hurt.png`, and `rune_archer_death.png`.

Recommended frame size: 32x32.

Animations should clearly show ranged attack preparation while keeping projectile visibility separate from the body sprite. Attack windup visuals should line up with the existing AI behavior without changing speed, damage, health, collision, or reward logic.

V1.5.3 uses generated fallback visuals for rune identity, cast warning, projectile color, hit flash, and rune-shard death feedback. Formal sprite sheets should keep ranged pressure and cast timing readable.
