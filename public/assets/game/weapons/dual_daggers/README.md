# dual_daggers

Future dual dagger attack sheets. Recommended name: `relic_hunter_dual_daggers_attack.png`.

Use this directory for dual dagger visual attack resources only. The animation can show two quick cuts, but it must not alter the existing two-hit damage logic, range, cooldown, knockback, kill handling, or lifesteal behavior.

Naming and manifest rules should follow `docs/art-resource-pipeline.md`.
