# lingxu_dungeon

Future first-floor tilesets and props. Recommended names: `lingxu_dungeon_tileset.png`, `lingxu_dungeon_props.png`, and `lingxu_dungeon_doors.png`.

Recommended tile size: 32x32.

Future assets can include floors, walls, doors, chest pedestals, source-crystal decorations, cracks, pollution marks, merchant props, event objects, and boss-room boundary details. Tiles should support the first-floor dark dungeon and cyan-green source-crystal style while keeping combat readability clear.

V1.5.2 currently uses generated Phaser Graphics room art as the fallback baseline. Future formal tileset PNGs should replace only the visual layer and must not change room collision, route logic, door placement, reward flow, combat hitboxes, or J/K/L feel.
